# Regras / Rules

| Ficheiro / File | Conteúdo / Content |
|---|---|
| `regras_vacinas.csv` | Vacinas: indicação, esquema, acesso, momento face à imunossupressão e fonte (português) |
| `regras_vacinas_en.csv` | Vaccines: indication, schedule, access, timing relative to immunosuppression and source (English) |
| `farmacos_vacinas_vivas.csv` | Intervalo mínimo após suspensão de cada fármaco até vacina viva (português) |
| `farmacos_vacinas_vivas_en.csv` | Minimum interval after discontinuing each drug before a live vaccine (English) |

As versões inglesas são traduções das portuguesas, linha a linha. As regras aplicam as recomendações portuguesas (DGS, PNV) e o Protocolo CARI 2026; o acesso gratuito refere-se ao SNS.

The English files are line-by-line translations of the Portuguese ones. The rules apply Portuguese national recommendations (DGS, PNV) and the CARI protocol 2026; free access refers to the Portuguese National Health Service (SNS).

UTF-8, separador vírgula / comma-separated.
